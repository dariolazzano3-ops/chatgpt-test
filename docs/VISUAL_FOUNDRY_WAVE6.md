# PROJECT VISUAL FOUNDRY — Wave 6 VisualDelta V1

Wave 6 converts deterministic measurements into explicit delta records.

Categories: STRUCTURE, GEOMETRY, TYPOGRAPHY, COLOR, EFFECT, ASSET, CONTENT, RESPONSIVE.

Severities: INFO, LOW, MEDIUM, HIGH, CRITICAL.

Every CRITICAL delta is blocking. Critical regions can elevate local deviations independently of the global page score. Delta records retain expected/actual/difference/unit/score/evidence and a bounded repair hint.
