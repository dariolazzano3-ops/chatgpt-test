# PROJECT VISUAL FOUNDRY — Wave 12 Bounded Visual Delta Closer

Wave 12 extends the existing `scripts/qa-repair-loop.mjs` host rather than introducing a second autonomous factory.

Repair order is STRUCTURE → MACRO GEOMETRY → COMPONENT GEOMETRY → TYPOGRAPHY → COLOR → EFFECT → MICRO SPACING.

Every successful repair iteration enforces repair → commit → render → measure → compare → functional regression. Frontend authority is restricted to files under the current project path and blocks worker/backend/config/database/auth/billing paths.

The visual iteration hard maximum is 8. No deterministic progress, functional regression, or exhaustion returns HUMAN_DECISION_REQUIRED rather than looping indefinitely.
