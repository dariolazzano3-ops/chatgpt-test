# PROJECT VISUAL FOUNDRY — Wave 10 Semantic Visual Review

Semantic review is additive only. It may identify hierarchy, density, focus, missing visual elements, unexpected reinterpretation, and stylistic drift.

It cannot delete deterministic VisualDeltas and cannot override a deterministic FAIL. Its findings are converted into additional VisualDelta V1 records. Deterministic browser/image measurement remains the only machine acceptance authority.

If no semantic provider is available, the layer returns NOT_EXECUTED_PROVIDER_UNAVAILABLE and preserves all deterministic deltas unchanged.
