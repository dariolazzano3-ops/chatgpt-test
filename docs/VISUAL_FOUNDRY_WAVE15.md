# PROJECT VISUAL FOUNDRY — Wave 15 Typography Contract

Fonts are first-class visual evidence: family, source, weight, size, line height, letter spacing, license, fallback, loaded state, and optional font metrics.

A missing or substituted approved font creates FONT_SUBSTITUTION_DELTA. Unknown licensing creates FONT_LICENSE_BLOCKER. Size/line-height/letter-spacing are measured separately.

A font mismatch cannot be hidden behind an otherwise-good layout score.
