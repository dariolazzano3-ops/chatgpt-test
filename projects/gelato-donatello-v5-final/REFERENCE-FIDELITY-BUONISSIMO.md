# BUONISSIMO REFERENCE FIDELITY PASS

Reference: https://buonissimo-online.de/

This pass intentionally follows the reference site's visual principles without copying its brand, copy or assets.

Observed reference principles translated into Donatello:
- large condensed editorial typography
- sage / cream / cocoa / sand palette
- square, wide CTA buttons rather than pill UI
- image-dominant alternating full-width sections
- large product tiles with photography + bottom gradient overlays
- strong 5% page gutters and 1140px content rhythm
- very little card chrome; borders/radii/shadows are de-emphasized
- home hero behaves as a branded color field with oversized type + product image
- mobile collapses to one-column image-first editorial blocks

Donatello-specific content and owner-provided photography remain authoritative.
