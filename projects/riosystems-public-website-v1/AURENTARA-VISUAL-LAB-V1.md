# AURENTARA SYSTEMS — Visual Lab V1

## Mission
Migrate the existing Framer visual lab from the former RIOSYSTEMS customer-facing identity to AURENTARA SYSTEMS without rebuilding the technical website or creating a second architecture.

Framer remains a visual design laboratory only. GitHub / Cloudflare remain the technical source of truth.

## Brand architecture

YSRIO GROUP
→ ownership / holding brand in the background

AURENTARA SYSTEMS
→ visible operating/customer brand

RIOSYSTEMS
→ internal technical foundation only where still useful

No public competition between YSRIO GROUP and AURENTARA SYSTEMS.

## North Star

70% trust + clarity
20% premium + authority
10% controlled wow

Primary positioning:
**WE BUILD THE SYSTEMS BEHIND YOUR BUSINESS.**

Secondary line:
**YOU RUN THE BUSINESS. WE BUILD WHAT MAKES IT RUN.**

The visual experience must communicate that AURENTARA SYSTEMS builds connected business systems, not just websites.

## Visual direction

Target feeling:
- calm
- precise
- premium
- trustworthy
- international
- technologically strong
- sovereign

Avoid:
- AI startup template
- crypto
- gaming / HUD
- cyberpunk
- generic SaaS
- overloaded agency design
- decorative sci-fi

Retain and refine:
- near-black / graphite surfaces
- titanium / silver details
- restrained System Blue + Violet activation
- strong negative space
- Swiss / neo-grotesk typography
- architectural system visualization
- subtle motion
- CSS/SVG-portable effects

## Wordmark direction

Visible wordmark:
**AURENTARA SYSTEMS**

Rules:
- uppercase
- disciplined tracking
- calm neo-grotesk
- AURENTARA may carry more optical weight
- SYSTEMS may be optically quieter, but remains integral
- no futuristic display font
- no decorative monogram that harms trust

## Core direction

Replace visible R / RIOSYSTEMS Core language with an AURENTARA-aligned system mark.

Explore an A-based modular/architectural mark only if it remains:
- simple
- memorable
- premium
- reproducible in SVG/CSS
- usable as favicon / app icon / core symbol later

The Core must read as connected business architecture, not a cockpit.

Public modules:
- BRAND
- WEBSITE
- LEADS
- CRM
- AI
- AUTOMATION
- OPERATIONS
- ANALYTICS

Additional service-page concepts may later include Growth, Support and Reputation.

## Hero task

Build/refine the AURENTARA SYSTEMS hero using the existing North-Star composition as the visual quality benchmark.

Keep:
- left copy / right system architecture
- headline: WE BUILD THE SYSTEMS BEHIND YOUR BUSINESS.
- restrained blue/violet energy
- existing strong negative space

Improve toward reference quality:
- Core depth
- nested system layers
- radial routing architecture
- module integration
- meaningful micro-density
- titanium / graphite material language
- selective activation paths
- navigation precision
- premium CTA treatment

Do not copy any unverified KPI, case-study or performance number from previous mock references.

## Mobile

Mobile must be purpose-built.

Order:
1. Wordmark / navigation
2. Headline
3. Supporting copy
4. CTAs
5. simplified Core

Initially show only key Core relationships such as Website, CRM, AI and Automation rather than squeezing the full desktop network into 390px.

## Motion

Suggested sequence:
1. central Core appears
2. inner layers activate
3. routing field appears
4. selected paths energize
5. modules connect
6. system becomes almost static

After activation, motion must remain extremely subtle.

Support a reduced-motion equivalent conceptually.

## Portability rule

Prefer effects reproducible with:
- SVG
- CSS
- transforms
- masks
- gradients
- lightweight JavaScript

Flag any Framer-specific effect and define a portable alternative.

## Hard gates

No publish.
No domain connection.
No paid Framer feature.
No external credentials.
No real customer data.
No fabricated customer claims, metrics, testimonials or outcomes.
No Production.
